# Archivo del sitio anterior

Texto íntegro de las 41 fichas de tratamiento publicadas en [luvania.com](https://luvania.com) el 19 de noviembre de 2026. La página `/tratamientos/x` del sitio viejo no es un tratamiento y no se archivó.

Estos archivos no se renderizan y no entran al sitemap. Sirven de fuente para reescribir las guías. El texto se guardó tal cual, incluidas las promesas que la web nueva no debe repetir.

`porcenalizacion` es el slug viejo, con la letra cambiada. En `treatments.json` el slug es `porcelanizacion`.

La ficha `manchas` en el sitio viejo solo contiene la palabra `body`. No había artículo que copiar.
